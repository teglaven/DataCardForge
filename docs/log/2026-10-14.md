重新启动 8 月搁置的前端选型，结论是 **Web**，并直接给出可运行的实现（不只是对比表）。

### 3. 踩坑（值得记）

1. **`display: inline-block` 击穿 flex 布局**：react-rnd 会在卡片上写内联 `display`，覆盖了样式表里的 `display: flex`，导致 10 000 行表格**把卡片撑高**而不是内部滚动——虚拟滚动完全失效。用 `display: flex !important` 修正。**这是纯 CSS 优先级问题，但症状看起来像"虚拟滚动没实现"**。
2. **`Number.isNaN(parse(token))` 做标题行判断是错的**：只要解析函数带兜底值（`parseNumeric(token, 0)`），`temp` 也会"看起来是数字"，于是标题行被当成数据吞掉。判定必须基于**词法**（正则）而不是解析结果。
3. **空状态按钮点不动**：`.canvas__cards` 这层绝对定位容器挡住了指针事件。修法是给容器 `pointer-events: none`、只给卡片 `auto`。
4. **Qt 版"切文件→图表联动"其实从未生效**：`ChartCard::SourceRef` 记的是 `matrixId`，而一个卡片装多个文件时每个文件是**不同的 matrixId**，所以切换文件后图表仍读旧矩阵。Web 版把依赖挂在**卡片**上并重指矩阵，这条规则才真正成立。
5. **依赖从 `matrixId` 改为"卡片 id"**：连带影响关闭保护（`hasDependents` 判断对象）、快照恢复（需由 line 反查所属矩阵卡）三处。

### 5. 图表库审计 + 统计图型补齐（第二轮）

新需求：图表要覆盖科研常用样式，并能导出矢量图保存/下载。先**审计再决定换不换库**。

**审计结论：ECharts 两项能力都已具备，不换库**（依据是实地核对 `node_modules/echarts`，不是文档印象）：

- 矢量导出是原生能力：`renderer: 'svg'` + `getSvgDataURL()`（类型定义中 `RendererType = 'canvas' | 'svg'`，
  `getDataURL` 的 `type` 明确含 `'svg'`）。
- `lib/chart/` 实际内置 `bar/boxplot/heatmap/scatter/line/custom/…`，常见统计图基本齐备。
- **只有两个缺口：误差棒、小提琴图**——用 ECharts 真正的 `custom` series（矢量图元）补齐，
  因此**没有牺牲矢量导出**。

于是新增 **9 种图型**并按「矢量优先」重做导出管线：

| 新增 | 说明 |
|------|------|
| 直方图 | 自算分箱（Sturges 或指定），最大值归末箱 |
| 回归图 | OLS + 斜率 + **R²** + n，t 分布 95% 区间 |
| 箱线图 | 五分位 + **Tukey 离群点** |
| 小提琴图 | **KDE 密度轮廓** + 四分位线（`custom` series） |
| 均值±误差棒 | **SD / SE / 95% CI**（`custom` series） |
| 相关性热力图 | 两两 **Pearson** 矩阵 + 发散配色 |
| 散点/柱状/折线 | 补多列、对数轴、次坐标轴、分组/堆叠 |
| **SVG 导出** | 序列化**活 DOM 树**，内联计算样式，**无内嵌位图** |
| PNG 1×/2×/4× | 高分辨率位图 |
| **PDF** | **手写无依赖生成器**（解析 PNG、拆 RGB/alpha、按需 `/SMask`）；UI 明确标注**非矢量** |

统计量集中在 `core/stats.ts`（纯函数、40 个测试），数值约定对齐 NumPy/R。

#### 本轮踩的坑（值得记）

1. **`Extract<SeriesOption, {type:'custom'}>` 在 ECharts 6 解析为 `never`**——联合成员的判别属性是
   可选的，于是类型断言**静默退化为 `any`**，等于没检查。正确做法是从包根导入
   `CustomSeriesOption` / `CustomSeriesRenderItem` / `CustomSeriesRenderItemAPI`。
   **这是"能编译但没在检查"的典型**，值得警惕。
2. **小提琴图两次画错**：先把宽度按数据轴比例算（图形撑满整个卡片），
   再把**密度峰值**当成 Y 轴范围（图形被拉伸到只剩一个斜率）。正确模型是
   **曲线沿数值轴绘制、宽度编码密度**（与 Matplotlib/Seaborn 一致）。已写成测试锁定。
3. **误差棒的图例重复**：背衬 scatter 与 custom 系列都带 `name` → 图例出现两项且标签重复。
   ECharts 没有「不入图例」的开关，改为**让几何系列不带名字**（无名即无图例项）。
4. **常数序列的相关系数原本返回 0**，等于谎称"不相关"；相关性数学上未定义，改为返回 `NaN`，
   热力图里再降级为 0 显示。
5. **散点图 10 000 点 → ~1 MB SVG**（每个散点一条 path）。改为**默认截断 5 000 点**
   （确定性等距抽取、保留首尾），渲染与导出体积都可接受。
